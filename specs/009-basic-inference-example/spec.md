# 기능 명세: 기본 추론 예제

**기능 식별자**: `009-basic-inference-example`  
**작성일**: 2026-09-15  
**상태**: 초안

## 개요

운영자는 별도 모델 없이도 파이프라인의 추론 모듈 계약과 프레임 전달 동작을 확인하고, 출력 영상 우측 상단에 현재 시간을 표시할 수 있는 기본 추론 예제를 사용할 수 있어야 한다.

## 사용자 시나리오 및 검증

### 사용자 스토리 1 - 기본 프레임 통과 예제 사용 (우선순위: P1)

운영자는 기본 추론 예제를 지정하여 모델 추론을 수행하지 않는 환경에서도 GPU 프레임이 손실되지 않은 채 인코딩 단계까지 전달되고, 우측 상단에서 현재 시간을 확인한다.

**우선순위 근거**: 실제 모델을 연결하기 전에 파이프라인과 추론 모듈의 호출 계약을 독립적으로 검증할 수 있다.

**독립 검증**: 추론 실행 및 비실행 요청 각각에서 동일한 입력 프레임 객체가 반환되고, 우측 상단에 현재 시간이 표시되는지 확인한다.

**인수 시나리오**:

1. **조건** 기본 추론 예제가 로드되었을 때, **행동** GPU 프레임을 전달하면, **결과** 우측 상단에 `yyyy-mm-dd hh24:mi:ss` 형식의 현재 시간이 표시된 원본 프레임 객체가 다음 단계로 반환된다.
2. **조건** 기본 추론 예제가 이미 추론 실행 요청을 처리했을 때, **행동** 추론 비실행 요청으로 GPU 프레임을 전달하면, **결과** 직전 추론 결과 시간이 표시된 프레임이 반환된다.

### 예외 상황

- 기본 예제는 모델 파일, 네트워크 또는 별도 추론 장치에 의존하지 않아야 한다.
- 시간 오버레이가 지원하지 않는 픽셀 형식의 프레임에는 명확한 오류를 반환해야 한다.

## 요구사항

### 기능 요구사항

- **FR-001**: 기본 추론 예제는 파이프라인이 호출할 수 있는 `on_frame(frame, infer=...)` 진입점을 제공해야 한다.
- **FR-002**: 기본 추론 예제는 `GpuFrame.set_frame_data`를 사용하여, 입력 NV12 프레임의 우측 상단에 녹색 시간을 `yyyy-mm-dd hh24:mi:ss` 형식으로 표시해야 한다.
- **FR-003**: 기본 추론 예제는 `infer=True`일 때 시간을 갱신하고, `infer=False`일 때 직전 결과를 재사용해 오버레이한 입력 `GpuFrame` 객체를 반환해야 한다. 아직 결과가 없을 때의 첫 비추론 호출은 현재 시간을 초기 결과로 사용한다.
- **FR-004**: 기본 추론 예제는 외부 모델 파일이나 별도 런타임 설정 없이 로드 가능해야 한다.
- **FR-005**: 기본 추론 예제는 입력 프레임의 GPU 식별자, 영상 메타데이터 및 시간 정보를 변경해서는 안 된다.

### 주요 개체

- **GPU 프레임**: 파이프라인이 기본 추론 예제에 전달하고 이후 인코딩 단계가 소비하는 영상 프레임과 메타데이터이다.

## 성공 기준

- **SC-001**: 추론 실행과 비실행 요청 각각 100회에서 입력 프레임 객체와 반환 프레임 객체가 모두 동일하고, 우측 상단에 시간 문자열이 표시된다.
- **SC-002**: 두 요청 유형의 모든 검증에서 GPU 식별자, 영상 메타데이터 및 시간 정보가 100% 보존된다.
- **SC-003**: 기본 예제는 모델 파일 및 CUDA 환경 변수가 없는 환경에서도 로드된다.

## 가정

- 파이프라인 조정 계층은 추론 모듈을 로드하고 `on_frame`을 호출하는 책임을 계속 가진다.
- 실제 모델 추론, 검출 결과 오버레이 및 CUDA YOLO 예제의 동작은 이 기능의 범위에 포함하지 않는다.
- 기본 예제의 시간 오버레이는 NV12 GPU 프레임을 대상으로 한다.

## 현재 구현 기준

- 구현 파일은 `examples/inference.py`이다. `torch.from_dlpack()`으로 NV12 GPU 버퍼를
  zero-copy tensor view로 만든다.
- 문자 픽셀은 NV12 luma(Y=150) 및 chroma(U=43, V=21) 평면에 기록되어 녹색으로
  표시된다. 프레임 너비·높이는 짝수여야 하며, luma와 chroma 평면이 모두 없으면
  `ValueError`를 발생시킨다.
- 마지막 시간 문자열은 모듈 수준에서 보관한다. 이 예제는 객체 검출 모델을 포함하지
  않으므로, 여기서 말하는 이전 추론 결과는 마지막으로 생성한 시간 문자열이다.
