# 기능 명세: YOLO 차량 검출 예제

**기능 식별자**: `009-basic-inference-example`
**최종 갱신일**: 2026-09-18
**상태**: 구현됨

## 개요

운영자는 실시간 영상에서 자동차를 검출하고, 출력 영상에서 검출된 각 자동차의 위치를 초록색 사각형으로 확인할 수 있어야 한다. 영상은 추론과 인코딩 사이에서 프레임 전체를 CPU 메모리로 복사하지 않고 계속 처리되어야 한다.

## 사용자 시나리오 및 검증

### 사용자 스토리 1 - 자동차 검출 결과 확인 (우선순위: P1)

운영자는 차량 검출 예제를 파이프라인에 지정하고, 입력 영상에서 자동차가 발견될 때 해당 자동차를 둘러싼 초록색 사각형을 출력 영상에서 확인한다.

**우선순위 근거**: 차량 검출 결과를 영상에서 즉시 식별할 수 있어 모델 연결과 운영 상태를 검증할 수 있다.

**독립 검증**: 자동차가 포함된 NV12 입력 영상을 처리했을 때 검출된 자동차에 대응하는 초록색 사각형이 출력 영상에 표시되는지 확인한다.

**인수 시나리오**:

1. **조건** 차량 검출 모델과 자동차가 포함된 입력 영상이 준비되었을 때, **행동** 추론 요청 프레임을 처리하면, **결과** 검출된 자동차마다 초록색 사각형이 표시된 동일한 프레임 객체가 다음 단계로 반환된다.
2. **조건** 직전 추론 요청에서 자동차 위치가 검출되었을 때, **행동** 추론이 생략된 프레임을 처리하면, **결과** 직전의 자동차 위치가 표시된 프레임이 반환된다.
3. **조건** 자동차가 검출되지 않았을 때, **행동** 프레임을 처리하면, **결과** 프레임은 사각형 없이 다음 단계로 반환된다.

### 예외 상황

- 지원하지 않는 픽셀 형식 또는 짝수가 아닌 너비·높이의 영상은 명확한 오류로 거부한다.
- 모델 경로 또는 신뢰도 설정이 없거나 유효하지 않으면 문서화된 기본값을 사용한다.
- 입력 영상 크기가 모델의 처리 단위와 맞지 않더라도, 원본 영상의 검출 위치가 유지되어야 한다.

## 요구사항

### 기능 요구사항

- **FR-001**: 예제는 파이프라인이 호출할 수 있는 `on_frame(frame, infer=...)` 진입점을 제공해야 한다.
- **FR-002**: 예제는 추론 요청 프레임에서 자동차만 검출하고, 자동차 이외의 객체에는 사각형을 표시하지 않아야 한다.
- **FR-003**: 예제는 검출된 각 자동차 위치에 초록색 사각형을 표시하고, 입력 프레임 객체를 다음 단계로 반환해야 한다.
- **FR-004**: 예제는 추론이 생략된 프레임에서 가장 최근의 자동차 검출 결과를 재사용해야 한다. 이전 결과가 없는 첫 호출에서는 검출을 수행해야 한다.
- **FR-005**: 예제는 프레임 전체를 CPU 메모리로 복사하지 않고 처리하며, GPU 식별자와 영상 메타데이터를 변경해서는 안 된다.
- **FR-006**: 예제는 모델 위치와 최소 신뢰도 설정을 받을 수 있어야 하며, 기본 모델과 기본 신뢰도를 제공해야 한다.

### 주요 개체

- **GPU 프레임**: 파이프라인이 예제에 전달하고 이후 인코딩 단계가 소비하는 영상과 메타데이터이다.
- **자동차 검출 결과**: 각 자동차의 영상 내 사각형 위치를 나타내며, 다음 추론 요청 전까지 재사용될 수 있다.
- **모델 설정**: 사용할 차량 검출 모델의 위치와 최소 검출 신뢰도이다.

## 성공 기준

- **SC-001**: 자동차가 포함된 검증 영상에서 검출된 자동차의 100%에 초록색 사각형이 표시된다.
- **SC-002**: 추론 실행 및 생략 요청 각각 100회에서 입력 프레임 객체와 반환 프레임 객체가 동일하며, GPU 식별자와 영상 메타데이터가 100% 보존된다.
- **SC-003**: 32의 배수가 아닌 짝수 해상도의 검증 영상도 처리 실패 없이 자동차 위치를 원본 영상 좌표에 표시한다.
- **SC-004**: 자동차가 없는 검증 영상은 오탐 사각형 없이 다음 단계로 전달된다.

## 가정

- 파이프라인 조정 계층은 예제 모듈을 로드하고 프레임마다 `on_frame`을 호출한다.
- 모델은 자동차 클래스를 구분할 수 있고, 실행 장치에서 사용할 수 있다.
- 입력 영상은 NV12 형식이며 너비와 높이가 짝수이다.
