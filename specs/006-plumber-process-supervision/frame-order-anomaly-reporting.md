# Feature Addendum: Out-of-Order Frame Reporting

**Feature identifier**: `006-plumber-process-supervision`

- **FR-013**: The three-second pipeline statistics report includes the
  non-negative `out_of_order_frame_count` field.
- **FR-014**: Plumber validates, stores, and exposes the latest
  out-of-order-frame total with the other pipeline statistics.
